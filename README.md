# E-COMMERCE SALES ANALYSIS DASHBOARD | POWER BI PROJECT

## Project Overview

This project is an interactive E-Commerce Sales Analysis Dashboard built using Power BI to analyze sales performance and gain meaningful insights related to profit, customers, payment modes, and product categories.

The goal of this project is to transform raw sales data into a visual and interactive dashboard that helps in better decision-making and business performance tracking.

---

## Tech Stack

- Power BI
- Power Query Editor
- DAX (Basic)
- Excel / CSV Dataset

---

## Data Source

Raw sales data provided in CSV format:

- Orders.csv
- Details.csv

---

## Data Cleaning & Transformation

- Cleaned and transformed raw sales data using Power Query Editor
- Checked and corrected data types
- Handled missing/null values
- Removed duplicate records
- Created relationships between tables
- Structured the dataset for analysis

---

## Dashboard Overview

- Sales Analysis
  - Profit-Loss by Month (Column Chart)

- Customer Analysis
  - Top Customers by Sales (Column Chart)

- Payment Analysis
  - Quantity by Payment Mode (Donut Chart)

- Category Analysis
  - Quantity by Category (Donut Chart)
  - Profit by Sub-Category (Bar Chart)

- Regional Analysis
  - Top States by Sales (Bar Chart)
---

## Key Insights

- Maharashtra generated the highest sales revenue.
- COD was the most preferred payment mode.
- Clothing category contributed the highest quantity sold.
- Printers generated the highest profit among all sub-categories.
- November recorded the highest monthly profit.
- May and July showed negative profit performance.
